# Flowdesk

Flowdesk is a simple project management dashboard built with React.  
The goal of this project was to create a clean, functional and fully responsive app that demonstrates real-world frontend skills.

## 🚀 Features

- Project creation with deadline
- Task management with completion tracking
- Automatic progress calculation
- Responsive dashboard layout (mobile & desktop)
- Sidebar navigation with mobile overlay
- Clean UI with CSS Modules

## 🛠 Tech Stack

- React
- React Router
- Context API (state management)
- CSS Modules
- JavaScript (ES6+)

## 📱 Responsiveness

Flowdesk is fully responsive:
- Sidebar collapses into a mobile menu
- Dashboard cards adapt to smaller screens
- Forms and lists scale correctly on mobile devices

## 🧠 What I Practiced

- Component-based architecture
- Global state management using Context API
- Derived state (progress calculation)
- Responsive layouts without UI libraries
- Clean and maintainable folder structure

## 📌 Future Improvements

- Authentication
- Persistent storage (backend or localStorage)
- Drag & drop for tasks
- Team member assignment
